# Погода по городам

## Требования

- Python 3.10 или новее.
- Доступ к интернету.

## Запуск

1. Убедитесь, что файлы `main.py` и `cities.txt` находятся в одной папке.
2. Выполните команду:

   ```bash
   python main.py
   ```

Программа читает список уникальных городов, получает текущую погоду через API `https://wttr.in/{City}?format=j1`, выводит название города, страну и текущую температуру, а затем рассчитывает по каждой стране количество городов, среднюю, минимальную и максимальную температуру.
